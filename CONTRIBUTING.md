# Contributing

1. Create a branch from `3.x` (`feature/...` or `fix/...`).
2. Run `composer qa` before opening a Pull Request.
3. Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
(`feat:`, `fix:`, `docs:`, `test:`, `chore:`, `ci:`, `build:`).
4. Breaking changes must be marked with `!` and noted in `UPGRADE.md`.
